2.  **Go to [Vercel.com](https://vercel.com) and Log in.**

3.  **Click "Add New..." -> "Project".**

4.  **Import your repository.**

## Option 2: Deploy via Command Line (Vercel CLI)

If you have the Vercel CLI installed, you can run:

```bash
vercel
```

Follow the prompts:
1.  Set up and deploy? **Y**
2.  Which scope? (Select your account)
3.  Link to existing project? **N**
4.  Project name? (Press Enter)
5.  Directory? (Press Enter)
6.  Want to modify settings? **N**

Once deployed, go to the project settings in the Vercel dashboard and add the Environment Variables listed above for better security.

## How to Change the URL (Domain)

The default URL generated by Vercel can be long. You can change it to something shorter (like `ahsania-store.vercel.app`) or use your own custom domain (like `ahsania.com`).

1.  **Go to your Vercel Dashboard:** [https://vercel.com/dashboard](https://vercel.com/dashboard)
2.  **Select your project:** Click on `solitary-meteorite`.
3.  **Go to Settings:** Click on the "Settings" tab at the top.
4.  **Select Domains:** Click on "Domains" in the left sidebar.
5.  **Add a Domain:**
    *   Type your desired name, for example: `ahsania-system.vercel.app`
    *   Click **Add**.
    *   If the name is available, it will be live instantly!
